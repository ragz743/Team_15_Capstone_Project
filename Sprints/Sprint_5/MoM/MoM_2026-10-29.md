The tables should have SELECT, INSERT, UPDATE, and DELETE permissions applied to them. The dashboard will store everything in those four tables:
  - **awn.table_llm_usage_requests**: contains the chatbot calls. A call is one question the chatbot answered from start to finish. The chatbot sends one after every question.
  - **awn.table_llm_usage_model_calls**: Each call makes embedding and chat requests to write the answer. This is where the tokens and cost live. Every row in this table belongs to a row in the above requests table.
  - **awn.table_llm_usage_quality_runs**: Once a day, the chatbot will ask a fixed set of sample questions and check whether it found the right weather data.
  - **awn.table_llm_usage_budget_alerts**: This records the monthly budget email and is sent once a month
	The chatbot will fill in the first 3 tables, and the dashboard backend will fill in the budget alerts table itself. Signed-in users aren’t stored in any of the four as the dashboard counts them from the awn.users table.
