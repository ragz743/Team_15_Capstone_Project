# Introduction
AgWeatherNet is a statewide weather observation network that delivers detailed, high-resolution agricultural weather information throughout Washington. The system converts raw meteorological measurements into actionable insights that help guide decisions related to crop management, farm labor, and animal health. This support plays an important role in improving resource efficiency and reducing the impacts of environmental and biological stresses on agriculture. While AgWeatherNet offers decision-support tools through its web and mobile platforms, many non-technical users struggle to access and interpret the information because of complex dashboards and the need to navigate structured database queries.

To address this challenge, this project proposes to implement an AI chatbot that allows natural language access to AgWeatherNet data. A prior attempt at this solution existed but suffered from issues with architectural inefficiencies and limited scalability. Consequently, the client has requested a complete system redesign to improve both performance and reliability.

The core objective of this project is to implement and deploy an efficient, scalable, and domain-aware AI chatbot. This system must be capable of accurately translating natural language questions into weather data queries and providing the users with analytical responses that support agricultural decision-making. Ultimately, this project aims to deliver a robust and production-ready AI chatbot that seamlessly integrates with AgWeatherNet’s existing data infrastructure while resolving the shortcomings of the prior implementation.
